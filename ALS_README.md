# ALS Progression Prediction – Round 2 🧠

This project is part of the *Statistics and Machine Learning in Bioinformatics* course at Aarhus University.

## 🗂 Overview

We used gene expression and clinical data to predict the ALS disease progression rate (dFRS).  
The final predictions were submitted as a `.rds` file.

## 🧠 Models Used

- Lasso Regression
- Ridge Regression
- Random Forest Regressor
- **Weighted Ensemble** (based on inverse RMSE)

## 📈 Final Ensemble Performance

- **Average RMSE**: 0.5212

## 📁 Files Included

- `als_prediction.ipynb`: Main Jupyter Notebook
- `final_predictions.csv`: Final predicted values
- `als_progression.team_ashkill.rds`: Submission-ready `.rds` file
