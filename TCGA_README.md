# TCGA Cancer Classification – Round 2 🧬

This project is part of the *Statistics and Machine Learning in Bioinformatics* course at Aarhus University.

## 🗂 Overview

We used high-dimensional gene expression data to classify samples as `"Tumor"` or `"Normal"`.

## 🧠 Models Used

- Logistic Regression
- Random Forest Classifier
- **Majority Voting Ensemble**

## 📊 Final Results

- **Ensemble Accuracy**: 0.9862
- **Team Error**: 0.0138

## 📁 Files Included

- `tcga_prediction.ipynb`: Main Jupyter Notebook
- `tcga_final_predictions.csv`: Final predictions
- `minitcga_cancer_classification.team_ashkill.rds`: Submission-ready `.rds` file
